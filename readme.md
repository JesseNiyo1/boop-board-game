# boop. — Python Board Game Recreation

A Python implementation of the strategic board game **boop.**, featuring a graphical user interface built with Tkinter and a 
modular game architecture. 


> **Status:** NOT DONE

---

## Overview

This project recreates the core mechanics of *boop.*, where players place kittens and cats on a 6×6 board. Every newly placed piece 
"boops" nearby pieces, causing them to move according to the game's rules. Kittens can be 
promoted into cats by placing them in a tic-tac-toe pattern, and players compete to form winning combinations, or by placing all their available pieces on the board.

---

## Current Gameplay

Current functionality includes:

* Placing kittens and cats
* Switching between available piece types
* Applying boop mechanics after each move
* Updating player inventories
* Detecting completed matches
* Displaying the current game state
